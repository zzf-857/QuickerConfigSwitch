# QuickerConfigSwitch

跨 Windows / macOS / Linux 的本地 Agent 配置快速切换工具。

- 给 Codex、Claude Code 等 Agent 一键切换到自定义 provider / 模型
- 只改必要的键，注释与格式原样保留；随时逐字节还原原配置
- 不碰官方登录文件：切回即恢复官方订阅
- Codex 切到第三方（如 CPA）后仍保留 Fast 模式

当前处于设计阶段，架构见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

参考项目：[yetone/magpie](https://github.com/yetone/magpie)（MIT）。
